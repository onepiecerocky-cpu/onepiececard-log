SYNC // クラウド同期（複数端末）オフ

Firebase の Realtime Database に保存し、全端末で共有します。全端末で同じ同期コードを入れてください。

初回は、データがある端末で「この端末→クラウド」を1回押してアップ。別端末では同じURL・コードを入れて「クラウド→この端末」で取得。以後は自動同期です。

同期が有効なら、毎日1回この端末のデータを自動でバックアップ（直近14日分を保持）。誤操作で消しても、日付を選んで戻せます。
